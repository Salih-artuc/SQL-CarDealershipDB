⚙️ Setup Instructions

The CarDealershipDB.sql file must be executed first. This script contains all essential database objects, including triggers, stored procedures, and functions, which are created and executed within the same file.

In the project directory, there is a Queries folder that includes five SQL query files. Each file is named according to its functionality and purpose.

Additionally, the Tests folder contains test scripts:

P files represent stored procedure tests
FN files represent function tests
T files represent trigger tests
